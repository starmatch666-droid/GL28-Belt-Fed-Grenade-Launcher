# GL-28 弹链榴弹发射器

《绝地潜兵 2》Lua 注入型模组，针对 **GL-28 弹链式榴弹发射器**。仅依赖 **Bingus Shared Loader（API 1）**，不需要任何共享定位器。

> ⚠️ 本 release 含**三个互斥版本**。它们改的是同一把武器，**按需求只启用其中一个，不要同时装**。

## 版本选择

### ① 弹链电榴弹 0.2.1 —— 电弧链保留，且不再伤到开火者

`GL28-Electric-Grenade-Launcher-0.2.1-experimental.zip`

GL-28 改用「缓和使者（GL-52 De-Escalator）」的**电榴弹**，10 米电弧链**一个字节都没删**，但电弧不再伤害开火者。

| 组件 | 改动 |
|---|---|
| GL-28 发射物 | `ProjectileType` 89 → **222**（缓和使者的电榴弹） |
| 射速 | 160 / 240 / 320 → **320 / 480 / 640 rpm** |
| 背包 容量/初始/补给箱 | 120 / 120 / 60 → **1200 / 1200 / 600** |
| 电弧（ArcType 15） | **指针替换**：复制 104 字节 ArcInfo → 偏移 100 的标记 `0 → 1` → 把副本挂进 ArcType 查找表（原数据零改写） |

电弧的距离 10 m、链数 2、伤害 100/70、1.75 秒电击状态**全部原样保留**。

**为什么用指针替换**：早期版本直接在内存里改 ArcSettings 第 15 行偏移 100 那个字节，实机**完全没效果** —— 引擎用的是它自己加载时拷贝的那份 ArcInfo。指针替换后，引擎无论从哪条路径读，读到的都是置位过的那份副本。

**实机验证：已通过**（2026-09-23，构建 25327279）。贴脸 / 近墙开火时自己不掉血、不被电弧电到，电弧照常链敌人。

> 注：若整合包里已有其他「电榴弹自伤回调」类模组，它与本包做的是同一件事（同一标记、同一查找表）。两个同时装不会打架 —— 谁先动手谁生效，后一个会**自动让位**（日志记 `arc_already_owner_safe_by_other_mod`），两种情况都算正常。

### ② 伤害 200 + 射速 ×2 + 弹容 ×10 0.1.3

`GL28-Damage200-2xRPM-Ammo10x-0.1.3-experimental.zip`

| 项目 | 原值 | 新值 |
|---|---|---|
| 伤害 / 耐久（40mm 爆炸） | 150 / 150 | **200 / 200** |
| 射速（三档） | 160 / 240 / 320 rpm | **320 / 480 / 640 rpm** |
| 背包 容量/初始/补给箱 | 120 / 120 / 60 | **1200 / 1200 / 600** |
| 穿甲 | AP4（重穿） | **不变** |

**状态**：射速与弹药已实测生效；0.1.3 修复了伤害被拒写的问题（锚行被你自己的 AMR 消音模组改过导致整行比对失败），**伤害 200 需重启后确认**。

### ③ 只加伤害 200 0.1.0

`GL28-Damage200-Only-0.1.0-experimental.zip`

只做一件事：把 40mm 爆炸伤害从 150/150 提到 **200/200**。射速、弹容、穿甲**全部不变**。

**状态**：离线 6 用例通过；**实机未测**。同一条数据的 200 伤害已在 ② 上实测通过。

## 依赖

**只需要 Bingus Shared Loader v15 及以上**（或兼容的新版本）。无需其他前置。

## 安装

1. 安装并启用 Bingus Shared Loader（API 1）
2. 用 Arsenal / HD2 Mod Manager 导入**选定的那一个** ZIP，部署后**完全重启游戏**
3. **三个包只装一个** —— 它们改的是同一把武器的同一批记录

Loader 放到列表最后（若开启「首个 mod 优先」则放最前）。

## 版本与适配

- 目标游戏构建：**25327279**
- 三个包均校验 `game.dll` 的 SHA-256：`73374bd4e38386beb9a23bef480082b67d457ebc77485fbec5f488b4e95e201f`，**其他构建会拒绝写入**
- 写入前逐项核对原始字节，任一校验不过就**一个字都不写**（fail-closed），不会强行覆盖

## 日志

三个包各有独立日志：

- `%LOCALAPPDATA%\CowboyBingus\Helldivers2\Logs\Gl28Electric.log`（① 电榴弹）
- `%LOCALAPPDATA%\CowboyBingus\Helldivers2\Logs\Gl28DamageRpmAmmo.log`（② 伤害射速弹药）
- `%LOCALAPPDATA%\CowboyBingus\Helldivers2\Logs\Gl28Damage200.log`（③ 只加伤害）

写入成功会记录 `applied_runtime_write_verified`；数据不匹配时记录 `*_not_write` 并**拒绝写入**。

## 注意

- 内存模组属**客户端运行时改动**：只在本次游戏会话内生效，退出游戏即恢复原状。
- 联机表现可能与队友不一致，并存在**反作弊风险**。建议仅在知情固定队环境中使用。
- 卸载：用管理器禁用本包并重新部署；手动安装需保持 `patch_N` 编号连续，**不要直接删除中间编号的文件**。
